## ⚡ What is Winland?

**Winland** brings a fluid, high-performance **Dynamic Island** and **Interactive Modern Taskbar** experience to Windows 10 and 11. Built with hardware-accelerated DirectX composition, ReadyToRun native compilation, and sub-millisecond spring dynamics, Winland transforms your desktop without sacrificing system performance.

### ✨ Highlights

- **🏝️ Ultra-Fluid Dynamic Island:**
  - Sub-millisecond native spring animations and micro-interactions.
  - Interactive notification hub, quick settings, device status, and clipboard history.
  - Custom surface materials: Glass, Translucent, Opaque, and adaptive dynamic Album Cover.
- **🎵 Real-Time Music Player & Visualizer:**
  - Direct integration with Spotify, Apple Music, YouTube Music, Chrome, and [Lyriic](https://github.com/jeetron1x/lyriic).
  - 64-band WASAPI spectrum visualizer synced to your audio output.
  - Dynamic palette extraction: island surfaces and scrubbers adapt smoothly to the current track's artwork.
  - Interactive seeker and timeline scrubber.
- **🚀 Interactive Modern Taskbar:**
  - Hover pop-out animations and smooth icon toggles.
  - Special Windows start orb animation.
  - Seamless native Windows taskbar auto-hiding with fail-safe unhide on exit or crash.
- **🌤️ Dynamic Animated Widgets:**
  - Real-time weather detection with dynamic live weather animations.
  - Minimalist day, date, and clock typography with full custom color wheel picker.
- **🛡️ Device Security & Privacy:**
  - Built-in device security and privacy monitoring.
  - 100% offline, local-only audio processing with zero network telemetry or tracking.
- **🎮 Zero Gaming & Performance Impact:**
  - Real-time full-screen game detection automatically suspends background rendering so competitive games run at full FPS uninterrupted.

## 📥 Installation

Download the official verified installer from [GitHub Releases](https://github.com/jeetron1x/Winland/releases/latest):

1. **[Download Winland-Setup.exe](https://github.com/jeetron1x/Winland/releases/latest/download/Winland-Setup.exe)**
2. Run `Winland-Setup.exe`.
3. Follow the one-click installer. Winland will launch automatically and create Start Menu and Desktop shortcuts.

> The installer is digitally certified and signed by **Jeetron1x**.

## 🔒 Security & Verification

Winland binaries are compiled with ReadyToRun Ahead-of-Time (AOT) machine code protection with debug symbols stripped, and are signed with Authenticode certification:

- **Verified Publisher:** `Jeetron1x`
- **Integrity:** Digitally signed with SHA256 & RFC3161 DigiCert timestamping.
- **Clean Uninstall:** Full uninstall support via Windows Settings > Installed Apps or `%LOCALAPPDATA%\Programs\Winland\Uninstall.exe`.
